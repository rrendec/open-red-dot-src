# Open Red Dot - source code and documentation

From Lenovo: *The ThinkPad Compact USB Keyboard with Trackpoint is a legendary,
award-winning, full size slim keyboard with island style keys design. To provide
a seamless user experience, this new Island style keyboard is mirroring the same
design, functions and technical specifications of the ThinkPad. The ThinkPad
Compact keyboard incorporates scissor lift key mechanism to ensure great
ergonomics and comfort. Larger keys as well as more space between keys help
maximize preciseness for a higher quality all day typing experience.*

Sadly, the original product has been discontinued as of 2026. This project aims
at creating a close replica using parts that are still available on the market.
Replacement ThinkPad keyboards can be found from multiple Chinese manufactures
on AliExpress. Because the original KU-1255 itself was designed to look and feel
identical to the ThinkPad keyboards, these replacement keyboards also have the
same look and feel. However, they are bare laptop keyboards with ribbon cables
connected directly to the key matrix. To turn them into a usable external USB
keyboard, a controller and a case are needed.

This project includes an open-source firmware for a custom controller. This is
**not** the firmware of the original KU-1255.

A separate project (link to be added) includes the CAD files:
* KiCad design files (schematics and layout) for the controller board.
* FreeCAD design files for the case.

The project also includes additional documentation and tools that have been used
throughout the design process.
