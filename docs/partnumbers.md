# KU-1255 Part Numbers

The generic model for the USB variant is KU-1255. There are various marketing
part numbers and service part numbers (FRU) depending on the keyboard layout
and language.

The table below was extracted from the
[Official Lenove Website](https://pcsupport.lenovo.com/us/en/products/laptops-and-netbooks/thinkpad-edge-laptops/thinkpad-edge-e535/accessories/pd026745-thinkpad-compact-usb-keyboard-with-trackpoint-overview-and-service-parts).

There is also a dedicated
[product page](https://pcsupport.lenovo.com/us/en/products/accessory/keyboard/thinkpad-compact-usb-keyboard-with-trackpoint)
but I couldn't find the specifications page there. The page linked above is in
the ThinkPad Edge E535 accessories section. Nevertheless, the product description
and part numbers are correct.
